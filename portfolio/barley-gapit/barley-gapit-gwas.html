Genome-Wide Association Analysis of Barley Leaf Rust Resistance with GAPIT

Prepare aligned phenotype, genotype, marker-map, and population-structure inputs for multi-model GWAS using GAPIT.

This project runs a multi-trait GWAS workflow using a filtered SNP matrix and four barley leaf-rust phenotypes: SRT_MRC, SRT_SAT, APR_SAT17, and APR_SAT19. The code is organized around GAPIT's input conventions: phenotype table (Y), genotype dosage table (GD), marker map (GM), and optional covariates (CV).

The example follows the supplied analysis structure, but sample matching and Q-matrix row alignment must be checked before the model is run. The scripts must be tested against the installed GAPIT version and local input files.

R code

Prepare GAPIT inputs from a vcfR object

⚠️
Input object type matters

vcf@gt works only when vcf is a vcfR object. If class(vcf) returns data.frame, import the VCF with vcfR::read.vcfR() or adapt the script to your actual table.

R · GAPIT
library(vcfR)
library(dplyr)
library(stringr)
library(GAPIT)

# 1. Import phenotype data and standardize IDs
pheno <- read.csv("pheno.csv", sep = ";", stringsAsFactors = FALSE)
pheno <- pheno %>%
  mutate(Taxa = str_replace(as.character(Taxa), "^AM-", ""))

traits <- c("SRT_MRC", "SRT_SAT", "APR_SAT17", "APR_SAT19")
required_cols <- c("Taxa", "RowType", traits)
stopifnot(all(required_cols %in% names(pheno)))
stopifnot(!anyDuplicated(pheno$Taxa))

# Numeric row-type covariate (six-row = 1; two-row = 0)
pheno$RowType_Num <- ifelse(pheno$RowType == 6, 1, 0)

# 2. Read the actual VCF as a vcfR object
geno <- read.vcfR("5OK_AM17.vcf", verbose = FALSE)
stopifnot(inherits(geno, "vcfR"))

gt <- extract.gt(geno, element = "GT")
gt_numeric <- ifelse(gt %in% c("0/0", "0|0"), 0,
              ifelse(gt %in% c("0/1", "1/0", "0|1", "1|0"), 1,
              ifelse(gt %in% c("1/1", "1|1"), 2, NA_real_)))
gt_numeric <- matrix(as.numeric(gt_numeric), nrow = nrow(gt),
                     ncol = ncol(gt), dimnames = dimnames(gt))

map <- data.frame(
  SNP = geno@fix[, "ID"],
  Chromosome = geno@fix[, "CHROM"],
  Position = as.numeric(geno@fix[, "POS"]),
  stringsAsFactors = FALSE
)

# 3. SNP QC: MAF >= 0.05 and missingness <= 0.10
maf <- apply(gt_numeric, 1, function(x) {
  p <- mean(x, na.rm = TRUE) / 2
  min(p, 1 - p)
})
snp_missing <- rowMeans(is.na(gt_numeric))
keep_snp <- is.finite(maf) & maf >= 0.05 & snp_missing <= 0.10
gt_qc <- gt_numeric[keep_snp, , drop = FALSE]
map_qc <- map[keep_snp, , drop = FALSE]

# 4. Filter individuals by missingness
keep_ind <- colMeans(is.na(gt_qc)) <= 0.10
gt_qc <- gt_qc[, keep_ind, drop = FALSE]
genotype_taxa <- colnames(gt_qc)

# 5. Synchronize phenotype and genotype IDs
common_taxa <- genotype_taxa[genotype_taxa %in% pheno$Taxa]
stopifnot(length(common_taxa) > 0)
pheno_gwas <- pheno[match(common_taxa, pheno$Taxa), , drop = FALSE]
stopifnot(identical(pheno_gwas$Taxa, common_taxa))
gt_qc <- gt_qc[, common_taxa, drop = FALSE]

# 6. Mean-impute missing SNP dosages after QC
for (i in seq_len(nrow(gt_qc))) {
  missing_i <- is.na(gt_qc[i, ])
  if (any(missing_i)) {
    gt_qc[i, missing_i] <- mean(gt_qc[i, ], na.rm = TRUE)
  }
}

# 7. Build GAPIT Y, GD and GM tables
my_Y <- pheno_gwas[, c("Taxa", traits), drop = FALSE]
my_GD <- as.data.frame(t(gt_qc), check.names = FALSE)
my_GD <- cbind(Taxa = rownames(my_GD), my_GD)
rownames(my_GD) <- NULL
my_GM <- map_qc
colnames(my_GM) <- c("SNP", "Chromosome", "Position")

# Optional numeric row-type covariate as CV.
# For sNMF ancestry covariates, replace this with an ID-aligned Q matrix.
my_CV <- data.frame(Taxa = common_taxa,
                    RowType_Num = pheno_gwas$RowType_Num)

# 8. Run selected GAPIT models for the four traits
myGAPIT <- GAPIT(
  Y = my_Y,
  GD = my_GD,
  GM = my_GM,
  CV = my_CV,
  model = c("MLM", "FarmCPU", "Blink"),
  PCA.total = 0,
  Multiple_analysis = TRUE,
  file.output = TRUE
)

Model interpretation

Use complementary models, not just the smallest p-value

  • MLM: accounts for relatedness through a kinship matrix; model configuration should be checked for the installed GAPIT version.
  • FarmCPU and BLINK: multi-locus approaches that can complement the mixed model.
  • Review QQ plots, Manhattan plots, effect sizes, marker quality, and consistency across traits/models.
  • Control multiple testing and distinguish exploratory associations from independently validated markers.

Reproducibility notes

⚠️
Important scientific checks

This template uses row type as a numeric covariate. It is not interchangeable with an sNMF Q matrix, and the supplied original code's qmatrix_k2[, 1] must be aligned by sample ID before it is used as CV. Also verify that the GT encoding, multiallelic variants, chromosome labels, and GAPIT input column names meet the requirements of your installed version.
