This project converts the published study “Genome-Wide Association Study of Leaf Rust Resistance at Seedling and Adult Plant Stages in a Global Barley Panel” into a reproducible learning and portfolio workflow. The analysis combines disease phenotypes with dense SNP genotypes to identify marker–trait associations (MTAs) for Puccinia hordei resistance.

The published study used 316 spring barley genotypes from the AM2017 association panel. After retaining mapped polymorphic SNPs and applying MAF ≥ 5% and missingness ≤ 10%, 36,793 SNPs were used for genetic analyses. Population structure was assessed with 2,065 highly informative SNPs in STRUCTURE; PCA was calculated with PLINK 1.9; kinship was calculated from the filtered marker set; and GWAS was conducted with TASSEL 5.2.53 and six GAPIT3 models. citeturn2search0

Phenotype Exploration

Inspect the four leaf-rust resistance traits before GWAS

The GWAS combined disease severity scores from two seedling tests and two adult-plant environments. Before association testing, inspect missing values, distributions and trait relationships. This does not replace the experimental phenotyping described in the paper; it is the computational QC layer before GWAS.

R
library(tidyverse)

traits <- c("SRT_MRC", "SRT_SAT", "APR_SAT17", "APR_SAT19")

# Missingness and descriptive statistics
pheno |>
  summarise(across(all_of(traits),
                   list(n = ~sum(!is.na(.x)),
                        mean = ~mean(.x, na.rm = TRUE),
                        sd = ~sd(.x, na.rm = TRUE),
                        min = ~min(.x, na.rm = TRUE),
                        max = ~max(.x, na.rm = TRUE))))

# Long format for trait distributions
long_pheno <- pheno |>
  pivot_longer(all_of(traits), names_to = "Trait", values_to = "Score")

ggplot(long_pheno, aes(Score)) +

SNP Quality Control

Apply the published MAF and missingness thresholds

The published analysis retained SNPs with known genetic/physical positions, removed monomorphic markers, removed markers with MAF < 5%, and removed markers with >10% missing data, resulting in 36,793 SNPs. The same MAF and missingness criteria were used for the GWAS. citeturn2search0

PLINK command-line QC

bash · PLINK 1.9
# Starting from a PLINK binary dataset: barley50k
plink --bfile barley50k \
  --maf 0.05 \
  --geno 0.10 \
  --make-bed \
  --out barley50k_QC

# Confirm retained markers
wc -l barley50k_QC.bim

If your starting file is HapMap, VCF or another array-specific format, convert it to a PLINK-compatible representation first. Do not silently change the thresholds if the goal is to reproduce the paper.

R QC summary from a numeric genotype matrix

R
# G is a numeric SNP matrix: rows = genotypes, columns = SNPs.
# Missing genotypes must be coded NA.
G <- as.matrix(G)

maf <- apply(G, 2, function(x) {
  p <- mean(x, na.rm = TRUE) / 2
  min(p, 1 - p)
})

missing_rate <- colMeans(is.na(G))

keep <- maf >= 0.05 & missing_rate <= 0.10
G_qc <- G[, keep, drop = FALSE]

c(markers_before = ncol(G),
  markers_after = ncol(G_qc))
✓
Expected published endpoint

The article reports 36,793 high-quality SNPs across the seven barley chromosomes after filtering. Your count will only match exactly if you start from the same underlying marker dataset and position-filtering rules.

Population Structure, PCA and Kinship

Model the genetic relationships that can create false associations

The published study selected 2,065 highly informative SNPs for STRUCTURE, used 100,000 burn-in iterations followed by 100,000 MCMC iterations, and identified K = 2 using ΔK. PCA was calculated with PLINK 1.9 using the 36,793 filtered SNPs. PC1 and PC2 explained 21.10% and 9.29% of the variation, respectively. Kinship was calculated from the filtered SNP set. citeturn2search0

TASSEL 5.2.53 — Complete GWAS Tutorial

Rebuild the primary association analysis used in the publication

TASSEL was the primary GWAS platform. The paper compared GLM (Q), GLM (PCA), MLM (Q + K), and MLM (K + PCA), found the MLM approaches better controlled false positives, and implemented MLM (K + PCA) for the final GWAS. TASSEL's MLM requires a kinship matrix and population-structure covariates; its official tutorial describes the same genotype + phenotype + structure + kinship workflow. citeturn2search0turn0search0

A) Prepare the TASSEL inputs

Use a HapMap genotype file with the filtered SNPs, a trait file whose taxon names match the genotype taxa, a PCA covariate file, and a kinship matrix. TASSEL supports HapMap and numerical trait/covariate formats and can calculate PCA and kinship from marker data. citeturn0search1turn0search7

TASSEL file logic
genotype:       barley_QC.hmp.txt
phenotype:      barley_traits.txt
population Q:   structure_Q.txt          # for GLM/MLM Q models
PCA:            barley_PCA.txt           # for GLM/MLM PCA models
kinship K:      barley_kinship.txt       # for MLM models

Traits to analyze:
  SRT-MRC
  SRT-SAT
  APR-SAT17
  APR-SAT19

B) Filter sites in TASSEL

  1. Import the filtered HapMap genotype file.
  2. Open Filter → Sites.
  3. Apply the same biological thresholds used in the paper: MAF ≥ 0.05 and missingness ≤ 0.10.
  4. Export the resulting genotype table for reproducibility.
  5. Keep marker names, chromosome and genetic/physical positions intact because these are needed for the MTA tables and Manhattan plots.
⚠️
Do not double-filter blindly

If your HapMap file has already been filtered to the 36,793-marker dataset, applying another filter is fine as a verification step but should not be described as producing the published number unless the starting dataset is the same.

C) Generate PCA and kinship in TASSEL

In the TASSEL GUI, select the filtered genotype data and run Analysis → PCA for principal components and Analysis → Kinship for the relationship matrix. TASSEL's PCA implementation numerically represents marker states and its kinship tools can derive relationships from genome-wide SNPs. citeturn0search7turn0search1

bash · TASSEL pipeline example
# Example TASSEL pipeline for an MLM analysis.
# Adapt file paths and population-structure columns to your files.

./run_pipeline.pl \
  -fork1 -importGuess barley_QC.hmp.txt \
  -fork2 -importGuess barley_traits.txt \
  -fork3 -importGuess barley_PCA.txt -excludeLastTrait \
  -fork4 -importGuess barley_kinship.txt \
  -combine5 -input1 -input2 -input3 -intersect \
  -mlm -mlmVarCompEst P3D -mlmCompressionLevel Optimum \
  -input4 -export barley_MLM_PCAK \
  -exportType Text

The command above follows the official TASSEL MLM pipeline pattern: intersect genotype/trait/structure data by taxa, then pass the kinship matrix to MLM. The exact CLI flags can vary with TASSEL releases, so the installed version's help output should be checked before execution. citeturn0search0

D) Compare the four TASSEL models

E) Run the final MLM (K + PCA)

Run the four traits separately. Record the model, marker, chromosome, genetic position, p-value, FDR/q-value, R² and allele effect. In the paper, a negative allele effect means the allele decreases disease severity (resistance), whereas a positive effect increases disease severity (susceptibility). citeturn2search0

TASSEL GUI checklist
For each trait:
  1. Load genotype + trait + PCA + K.
  2. Select the MLM analysis.
  3. Use PCA as the fixed population-structure covariate.
  4. Use K as the random relationship matrix.
  5. Run MLM.
  6. Export the association table.
  7. Save the model output with the trait name.

Outputs:

GAPIT3 Validation

Validate TASSEL signals with six complementary GWAS models

The article used GAPIT3 to validate loci with GLM, MLM, SUPER, MLMM, FarmCPU and BLINK. The purpose here is not to replace the primary TASSEL analysis, but to identify marker–trait associations supported across independent model assumptions. citeturn2search0

R · GAPIT3 template
library(GAPIT)

# Y must contain taxa IDs plus one phenotype column.
# GD = genotype data; GM = marker map.
Y <- pheno[, c("Genotype", "SRT_MRC")]
GD <- read.table("data/GD.txt", header = TRUE, check.names = FALSE)
GM <- read.table("data/GM.txt", header = TRUE)

# Run the model(s) supported by your installed GAPIT3 version.
gwas_mlm <- GAPIT(
  Y = Y,
  GD = GD,
  GM = GM,
  model = "MLM",
  PCA.total = 3,
  file.output = TRUE
)
⚠️
Version check

GAPIT3 function arguments and supported model names have changed across releases. Keep the exact GAPIT version in your analysis log and use ?GAPIT to confirm the argument names before running the template. The publication itself reports six GAPIT3 models; the code here is an analysis template, not a claim that a single call reproduces every model in every GAPIT release.

R
qq_plot <- function(p, title) {
  p <- p[is.finite(p) & p > 0 & p <= 1]
  expected <- -log10(ppoints(length(p)))
  observed <- -log10(sort(p))
  d <- tibble(expected, observed)

  ggplot(d, aes(expected, observed)) +
    geom_point(size = 1.2) +
    geom_abline(slope = 1, intercept = 0, linetype = "dashed") +
    labs(x = "Expected -log10(p)", y = "Observed -log10(p)", title = title) +
    theme_classic()
}

qq_plot(gwas$P, "SRT-MRC — TASSEL MLM (PCA + K)")

ℹ️
Published figure threshold

Figure 4 in the article displays a horizontal threshold at p < 0.001, corresponding to −log10(p) = 3. The reported significance decision for multiple testing, however, was based on pFDR/q < 0.05. Keep those two concepts separate.

D) FDR correction and significant MTAs

R
# Storey q-values: install qvalue if it is not already available.
library(qvalue)

gwas <- gwas |>
  mutate(qvalue = qvalue(P)$qvalues,
         significant = qvalue < 0.05)

sig <- gwas |> filter(significant)

nrow(sig)
write_csv(sig, "results/SRT_MRC_significant_MTA.csv")

If the TASSEL export already contains the paper's FDR/q-value column, use that published-model output directly rather than recalculating it unnecessarily. The code is provided to show how the multiple-testing step can be reproduced from raw p-values.

Breeding Interpretation

Translate statistical associations into breeding hypotheses

The biological interpretation is straightforward: an allele effect below zero indicates that the allele is associated with lower disease severity and therefore resistance on the study's scoring scale; a positive effect indicates higher severity and susceptibility. The study identified resistance at both seedling and adult stages, including common genomic regions, making the signals relevant to resistance breeding rather than only early-stage screening. citeturn2search0

The paper reports 14 genotypes resistant at seedling stage to both isolates, 12 genotypes resistant or moderately resistant at adult stage, and one genotype resistant at seedling stage and moderately resistant at adult stage. These accessions can be treated as germplasm candidates for validation and crossing, while significant SNPs provide starting points for marker-assisted follow-up rather than automatic diagnostic markers. citeturn2search1
